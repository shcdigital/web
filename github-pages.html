GITHUB PAGES
USO COMERCIAL

Anexo de Términos y Condiciones: uso de cuentas personales de GitHub y alojamiento en GitHub Pages con fines comerciales.

// Anexo — Mayo 2026

CONDICIONES
Y LÍMITES

01
Cuentas

USO COMERCIAL DE CUENTAS PERSONALES

Permisos de uso: los Términos de Servicio de GitHub permiten de manera explícita que una cuenta personal gratuita ejecute proyectos con fines comerciales. No existe penalización ni cobro obligatorio por operar un sitio comercial o repositorio privado bajo esta modalidad.

Propiedad e independencia: el proyecto y el código fuente se hospedan bajo la cuenta del cliente. Si en el futuro el proyecto requiere escalar a un esquema corporativo, la cuenta o el repositorio pueden migrarse sin interrupción del servicio hacia una Organización de GitHub.

02
Uso aceptable

ALOJAMIENTO EN GITHUB PAGES: CONDICIONES

GitHub Pages es un servicio diseñado para servir páginas web estáticas (HTML, CSS, JavaScript e imágenes). Su uso para sitios comerciales está sujeto a las siguientes pautas:

  • Sitios aceptados: sitios corporativos informativos, portafolios profesionales, páginas de aterrizaje (landing pages), catálogos digitales y blogs de marca.
  • Restricciones comerciales (uso prohibido): GitHub Pages no está diseñado para funcionar como una plataforma de comercio electrónico masivo (e-commerce con pasarelas de pago transaccionales complejas gestionadas en el mismo servidor), ni para revender servicios de hosting o alojar aplicaciones como un software como servicio (SaaS).
03
Límites

LÍMITES TÉCNICOS DEL SERVICIO GRATUITO

El uso del servicio dentro del plan gratuito de GitHub incluye las siguientes capacidades máximas por repositorio y sitio publicado:

Concepto Límite gratuito Impacto en el servicio
Ancho de banda (tráfico) 100 GB al mes Suficiente para miles de visitas mensuales en un sitio optimizado.
Tamaño del sitio publicado Máximo 1 GB Aplica a los archivos desplegados de la página web.
Tamaño del repositorio Máximo 1 GB (recomendado) Límite del código fuente guardado en GitHub.
Compilaciones (builds) Máximo 10 despliegues por hora Aplica al publicar o actualizar el contenido del sitio.
Minutos de CI/CD (Actions) 2.000 minutos al mes Tiempo asignado para automatizar actualizaciones o pruebas.

Nota sobre los límites: si un sitio supera de manera recurrente el límite de ancho de banda (100 GB/mes) o el almacenamiento, GitHub no aplica inmediatamente un cobro sorpresa, sino que puede suspender temporalmente el servicio de GitHub Pages o enviar una notificación para optimizar el contenido o migrar a un servidor dedicado.

04
Mantenimiento

RESPONSABILIDADES Y RECOMENDACIONES

  • Dominio personalizado: para dar un perfil comercial adecuado, se recomienda vincular un dominio propio (ejemplo: www.tuempresa.com). La configuración de registros DNS y la emisión del certificado de seguridad SSL/TLS no generan costo adicional en GitHub.
  • Resguardo de contenidos: las imágenes de muy alta resolución o archivos pesados (como videos o PDFs voluminosos) deben ser alojados en servicios de almacenamiento externos (como Google Drive, AWS S3 o Cloudinary) para no saturar los límites de GitHub Pages.
  • Pérdida o modificación de acceso: el cliente es el único responsable de mantener la seguridad y las credenciales de su cuenta de GitHub, incluyendo el acceso a su correo electrónico y la autenticación en dos pasos (2FA).
